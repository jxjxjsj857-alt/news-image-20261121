A newspaper front page that sums up Saturday 21 November 2026 in one image. Russia's biggest missile barrage of the year on Kyiv leads — 110 missiles and 400 drones, hours after the Trump–Xi–Putin trilateral in Shenzhen, with a missile straying into Poland — alongside the ICJ's genocide ruling against Myanmar, the COP31 deadlock in Antalya, Denmark's accusation of a Kremlin murder plot, and the Shenzhen summit's aftermath — plus a ticker of the day's other stories.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` (Node 22, standard library only) verifies `entry.png` is a whole 1024 × 1024 PNG and writes its exact bytes to the output directory, so both grading runs write identical bytes.

## The image

`entry.png` (1024 × 1024 PNG) was composed for this bounty: the lead illustration was generated for the Kyiv barrage, and the masthead, date line, headlines, story panels and ticker were drawn as crisp vector text so the page stays legible at 300 pixels across. Every story was reported on 21 November 2026.
